    Act on the feed

    Anyone can challenge a provisional decision once per round with one extra page from a configured host, or finalize after the deadline. These calls are signed with a throwaway key kept in this browser. Owner actions are in the next card.

    Owner actions

    For the contract owner (the account that deployed it). Paste the Studio test account key to unlock these. The key is kept in memory only and is never stored or sent anywhere except to sign transactions for Studionet. Use a Studio test key, never a key that holds real funds.

    Decisions are LLM readings of public pages, not legal determinations. Source code and evidence: github.com/Oziman13/genlayer-eventwitness-app
