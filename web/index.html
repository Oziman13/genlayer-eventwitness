EventWitness

A challengeable, multi-source status feed for one event, running as a GenLayer Intelligent Contract on Studionet.

Wallet

Not connected.

Every transaction is signed in your own wallet (MetaMask or any EIP-1193 wallet) on the GenLayer Studio network. This page never asks for, creates or stores a private key. Use a Studio test account, not one that holds real funds.

Contract

Set up a new event feed (deploys a new contract)

The connected account becomes the owner. Contract code is fetched from this repository (../contracts/event_witness.py) and sent as a deploy transaction you sign. Three sources on three distinct sites are required.
